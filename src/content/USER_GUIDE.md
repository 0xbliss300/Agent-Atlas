> Agent Atlas 使用指南随当前前端版本一同发布，说明已经实现并通过验收的功能。应用仅供本机使用，不提供账号、云同步或网络发布。

## 快速开始

首次打开应用时不会出现演示项目。你可以从页头选择“添加项目”，手工填写项目，也可以让浏览器读取你明确选择的项目目录或状态文件并生成可编辑草稿。

最短使用流程：

1. 选择“添加项目”。
2. 选择空白项目或一个内置模板。
3. 填写项目名称、一句话简介、状态、完成度和当前里程碑。
4. 检查可选的任务、阻塞项、技术信息和本地资源。
5. 创建项目并在详情页继续维护。
6. 定期从“设置”导出 JSON 备份。

页面使用 Hash 路由。你可以刷新页面或使用浏览器的前进、后退按钮，不需要为各个页面配置服务器重写规则。

| 主要页面   | 入口          | 用途                               |
| ---------- | ------------- | ---------------------------------- |
| 项目概览   | `#/`          | 浏览、搜索、筛选和置顶项目         |
| 开发工作台 | `#/workbench` | 汇总跨项目任务、阻塞项和停滞提示   |
| 研究笔记   | `#/notes`     | 创建和阅读项目关联的 Markdown 文档 |
| 使用指南   | `#/guide`     | 阅读当前这份本地指南               |

## 添加与编辑项目

项目名称、一句话简介、当前状态、完成度和当前里程碑是必填信息。状态可选择“规划中”“开发中”“已暂停”或“已完成”，完成度范围为 0～100。

高级信息中可以维护：

- 完整介绍与图标类型；
- 功能列表和三阶段路线图；
- 下一步任务与当前阻塞问题；
- 语言、框架、模型、数据源和本地启动命令；
- 本地目录、GitHub 地址、文档位置、演示地址和本地产物路径；
- 一行一条的人工开发记录；
- 最多 12 个标签、置顶状态以及多个项目集合。

功能列表每行使用 `功能名称 | 状态`，路线图每行使用 `阶段 | 说明 | done/current/next`。任务和阻塞项可以使用普通文本，也可以使用 `- [ ]`、`- [x]` Markdown 勾选格式。

```text
对话工作流 | 已完成
浏览器验收 | 开发中

基础能力 | 完成数据层 | done
当前迭代 | 接入前端页面 | current
后续增强 | 补充更多功能 | next
```

创建或编辑前可以套用模板。模板只会填充表单，必须由你检查并确认后才会保存项目。关闭包含未保存内容的表单时，页面会要求确认。

项目详情页提供编辑、复制和删除。复制会生成新的项目 ID；删除项目需要二次确认，并会同时删除其研究笔记、草稿、版本历史和自动事件，因此重要数据应先备份。

## 项目概览与组织

概览页会根据当前项目计算项目总数、开发中数量、平均完成度和最近更新。搜索会匹配项目名称、简介、当前里程碑、标签和技术关键词。

你可以组合使用状态、标签和集合筛选，并按最近更新、完成度或项目状态排序。选择“清除筛选”可以回到完整范围，结果数量会通过无障碍状态区域播报。

标签会自动去除首尾空格、空值和不区分大小写的重复项。每个项目最多 12 个标签，每个标签最多 24 个字符。卡片最多显示前三个标签，多出的标签以数量提示收起。

项目可在表单或概览卡片中置顶。置顶只会让项目在“最近更新”排序中提前，不会修改项目更新时间；完成度和状态排序不受置顶影响。

在“设置 → 项目集合”中可以创建、重命名、调整顺序和删除集合，一个项目可同时属于多个集合。删除集合只会解除关联，不会删除项目、研究笔记、任务、草稿、版本历史或时间线。

## 项目详情、任务与阻塞项

项目详情集中展示当前状态、完成度、里程碑、功能、路线图、项目链接、技术栈、运行信息、研究笔记、开发记录和自动变更时间线。

“下一步任务”可以直接勾选或重新打开，修改会立即写回项目。“当前阻塞问题”只显示未解决内容，可在开发工作台中标记解决。两类操作都会形成自动变更事件。

本地目录、文档路径和产物路径只是文本。对应按钮会复制文本，不会打开文件管理器。HTTP 或 HTTPS 资源可在新窗口打开；本地演示地址只有在相应服务已经运行时才有效。

## 开发工作台

[开发工作台](#/workbench)从现有项目和研究笔记实时派生执行视图，不保存额外的汇总副本。

默认执行顺序为：

1. 未解决阻塞；
2. 活跃项目的未完成任务；
3. 其他未完成任务；
4. 可能停滞的项目。

“可能停滞”不是项目事实，只表示项目尚未完成，且最后更新时间距今至少 14 天。工作台支持按项目、集合和内容类型筛选，也可以直接勾选任务、解决阻塞项或返回准确来源继续开发。

页面底部的“近期来源”提供最近项目和研究笔记入口。项目或集合筛选会同时限制执行队列和相关汇总。

## 研究笔记与版本恢复

[研究笔记](#/notes)是归属于具体项目的 Markdown 文档，与项目表单中的简短“开发记录”分开保存。

新建或编辑笔记时可以填写所属项目、标题和 Markdown 正文。桌面端并排显示编辑器与实时预览；移动端可在“编辑”和“预览”之间切换。预览支持标题、列表、任务列表、引用、链接、代码和表格。

编辑器会把未保存内容作为临时草稿保存在当前浏览器中。再次进入时可以恢复或丢弃草稿。每篇正式笔记保留最近 10 个版本，可查看字段变化和逐行正文差异，并选择旧版本恢复；恢复前当前正式内容也会进入历史，避免覆盖丢失。

草稿和正式版本历史均有明确边界：临时草稿不会进入 JSON 备份，正式版本历史会进入完整备份。

## 项目与笔记模板

添加项目时可使用“空白项目”“Agent 项目”“研究项目”和“自动化项目”。新建研究笔记时可使用“实验记录”“技术调研”“决策记录”和“复盘”等 Markdown 大纲。

项目表单和笔记编辑器都可以把当前结构保存为自定义模板，并支持重命名、复制、排序和删除。删除模板不会影响已经由它创建的项目或笔记。

项目模板默认排除项目 ID、名称、状态进度、更新时间、开发记录、本地路径、资源地址、Git 信息、研究笔记、历史和系统事件。状态、里程碑、开发记录、路径或资源只有在保存模板时逐项明确勾选才会纳入。笔记模板只保存标题和 Markdown 大纲。

## 自动变更时间线

项目关键变化会形成独立时间线，包括项目创建，状态、完成度和里程碑修改，任务勾选，阻塞项解决，本地状态应用，以及研究笔记创建、更新和删除。

一次保存中的多个核心字段变化会合并为一条事件；没有实际变化时不会制造事件。时间线可按项目、状态、任务、阻塞、本地读取和研究笔记类型筛选，并与人工开发记录明确分开展示。

研究笔记事件只保存笔记 ID、标题和动作，不复制完整正文。笔记删除后既有事件仍会保留并标记来源已删除。每个项目只保留最近 200 条自动事件，项目删除时会级联清理对应事件。

## Codex 项目上下文

项目详情页的“生成 Codex 上下文”会在浏览器本地即时生成结构稳定的 Markdown，帮助新的 Codex 会话接手项目。

上下文可包含项目目标、状态、完成度、里程碑、未解决阻塞项、未完成任务、技术栈、运行命令、路径和资源文本、最近开发记录、研究笔记索引，以及由你明确选择的笔记正文。

生成后先在面板中预览，再由你选择“复制 Markdown”或下载 `.md` 文件。内容不会自动发送给 Codex 或任何外部服务。项目路径、仓库地址和研究内容可能包含私人信息，请在复制或下载前检查。

## 从本地来源创建或更新

所有本地读取都必须由你主动选择文件或目录。网页不会扫描未授权路径，也不会根据表单中保存的路径文本自动访问文件系统。

添加项目时可以从以下来源生成草稿：

- JSON 状态文件；
- Markdown 文件；
- `package.json`；
- 你明确选择的项目目录。

目录模式只读白名单内的 README、TODO、状态 JSON、`package.json` 和 Git 分支/提交元数据。文件模式单文件上限为 1 MB，本次总读取量上限为 4 MB。读取结果会标记为“已检测”“需确认”或“未检测到”，你必须在普通表单中检查后再创建。

项目详情的“读取本地状态”使用同一授权边界。结果会先预览，只有选择“应用读取结果”后才会更新项目。应用操作会记录自动事件。

应用不会保存目录句柄、权限或文件内容，也不会虚构浏览器未提供的绝对路径。不支持目录选择的浏览器仍可选择单个状态文件。

## 备份、恢复与清空

在“设置 → 备份与恢复”中可以下载完整 JSON 备份。备份包含项目、Markdown 研究笔记、正式版本历史、自动变更时间线、自定义模板和项目集合；临时笔记草稿不进入备份。

导入方式有两种：

- **合并导入**：保留当前数据并加入备份；ID 冲突时生成新 ID，同时修正笔记、历史、时间线和集合关联。
- **替换导入**：使用备份中的数据替换当前项目、笔记、历史、时间线、模板和集合。

模板或集合名称冲突时会保留双方并生成清楚的副本名称。旧版仅包含项目的备份也可以导入，缺少的新数据会安全迁移为空。导入校验失败时不会覆盖现有数据。

“清空全部本地内容”会删除当前浏览器中的项目、研究笔记、历史、时间线、自定义模板和集合，且需要二次确认。执行前应先导出备份。

## 显示设置

“设置 → 显示偏好”可以控制：

- 是否显示已完成项目；
- 是否显示“最近更新”区域；
- 默认排序方式；
- 标准或紧凑显示密度。

显示偏好与业务数据一样保存在当前浏览器，但不属于完整 JSON 备份。设置面板还会展示当前项目、研究笔记、自动事件、自定义模板和集合数量，以及“网络发布已关闭”的本地状态。

## 本地数据与安全边界

项目坚持 local-first：

- 项目、笔记、历史、事件、模板、集合和显示偏好写入当前站点来源的浏览器本地存储；
- 不提供后端、账号、遥测、云同步或远程 Markdown 服务；
- Markdown 原始 HTML、脚本、事件属性和危险 URL 不会执行，远程图片不会加载；
- 外部 HTTP/HTTPS 链接在新窗口打开，并使用安全的窗口隔离属性；
- 文件和目录读取只发生在你明确授权之后；
- 本地路径只作为文本保存和复制；
- 应用不会自动发布，也不应被部署到公开网络。

`localStorage` 按浏览器、用户配置和站点来源隔离。更换浏览器、端口或主机名，可能看到另一份空数据。清除站点数据、使用隐私模式或重置浏览器可能删除数据，浏览器不会自动替你创建磁盘备份。

## 常见问题

### 为什么首次打开没有项目？

应用不会把开发夹具伪装成真实项目。请选择“添加项目”录入自己的内容。

### 为什么换了端口后项目不见了？

浏览器本地存储按站点来源隔离。端口、主机名、浏览器或用户配置变化后，可能进入另一份存储空间。请在原来源导出 JSON，再在新来源导入。

### 为什么本地路径不能直接打开？

普通网页不能随意打开本机文件。路径字段只作为文本保存，详情页提供复制操作；需要读取状态时，请主动使用文件或目录选择器授权。

### “可能停滞”表示项目出现问题了吗？

不是。它只是工作台根据“未完成且至少 14 天未更新”计算的提醒，不会修改项目状态。

### 删除集合或模板会删除项目吗？

不会。删除集合只解除项目关联，删除模板也不影响已有项目和笔记。

### 删除项目会发生什么？

删除项目不可撤销，并会清理关联研究笔记、草稿、正式版本历史和自动事件。建议先导出完整备份。

### Markdown 内容会上传吗？

不会。指南、研究笔记预览和 Codex 上下文都在浏览器本地处理，不调用远程渲染服务。

### 数据损坏或误删后怎么办？

如果有 JSON 备份，请使用“替换导入”恢复。导入前可先导出当前数据。没有备份时，浏览器不会自动从云端恢复数据。
